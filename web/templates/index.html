📘 종종이(JJ) 3단계 LOC 매매 전략 가이드

🛡️ 1. 위기준비금(AK) 시스템

종종이 전략은 계좌 개설 시 설정한 위기준비금 비율(기본 5%)을 평상시에는 엄격히 격리 보관합니다.

  • 평상시 (Normal/Safe): 시드의 5%를 현금 안전자산(AK)으로 격리하고, 나머지 95%(AR)로 8분할 운용합니다.
  • 급락장 (Risk-Off): 시장이 폭락 구간에 진입하면 누적된 위기준비금을 투자금(AR)에 전액 병합하여 바닥권에서 공격적으로 추가 매수합니다.

⚡ 2. 3단계 시장 모드 (Safe / Normal / Risk-Off)

과거 3일간의 종가 추세 및 변동성을 분석하여 매일 장전에 시장 모드를 자동 판정합니다.

  • Safe 모드: 안정적인 상승/횡보장. 4분할 LOC 매수, +2.75% 익절 청산.
  • Normal 모드: 통상적인 변동성 장세. 기본 4분할 LOC 매수 집행.
  • Risk-Off 모드: 연속 급락 위기장. 매수 간격을 넓히고 위기준비금을 가동하여 리스크 방어.

⚖️ 3. 당일 순 주문표 & 퉁치기(상계) 엔진

장전에 걸어야 할 익절 LOC 매도 주문과 신규 LOC 매수 주문의 가격대가 겹칠 경우, 불필요한 양방향 체결 수수료를 방지합니다.

  • 동일 또는 인접 호가대의 매수/매도 수량을 차감 상계(Netting)하여 순 주문만 도출합니다.
  • 미국 주식 정규장 시작 전에 키움/한투 등 HTS/MTS에 당일 주문표를 그대로 등록하면 하루 5분 운용이 완성됩니다.

  • 봇이 알려주는 내 프로필 정보 중 Id: 123456789 (숫자)를 복사하여 위 [챗 ID]에 붙여넣습니다.

☁️ 구글 드라이브(GAS) 실시간 연동 가이드 (3분 완성)
1. 구글 앱스 스크립트(Google Apps Script) 접속:
  • script.google.com (바로가기 ↗) 에 접속하여 구글 계정으로 로그인합니다.
  • 좌측 상단 [+ 새 프로젝트] 버튼을 누르고, 프로젝트 제목을 JongJong Sync 등으로 지정합니다.
2. 액션스크립트(GAS) 샘플 코드 복사 및 붙여넣기:
코드 편집기의 기존 function myFunction() {} 내용을 모두 지우고, 아래 코드를 붙여넣은 뒤 저장(Ctrl + S)합니다. 
// =====================================================================
// 종종이(JJ Invest) - Google Drive 실시간 계좌 동기화 스크립트
// =====================================================================
var FOLDER_NAME = "JongJongTrader";
var FILE_NAME = "accounts.json";

function getOrCreateFolder() {
  var folders = DriveApp.getFoldersByName(FOLDER_NAME);
  if (folders.hasNext()) return folders.next();
  return DriveApp.createFolder(FOLDER_NAME);
}

function getOrCreateFile(folder) {
  var files = folder.getFilesByName(FILE_NAME);
  if (files.hasNext()) return files.next();
  return folder.createFile(FILE_NAME, "[]", MimeType.PLAIN_TEXT);
}

function doGet(e) {
  try {
    var action = (e && e.parameter && e.parameter.action) || "download";
    if (action === "ping") {
      return ContentService.createTextOutput(JSON.stringify({
        status: "ok",
        message: "JongJong Google Drive Sync Connected!",
        timestamp: new Date().toISOString()
      })).setMimeType(ContentService.MimeType.JSON);
    }
    var folder = getOrCreateFolder();
    var file = getOrCreateFile(folder);
    var content = file.getBlob().getDataAsString();
    var updated = file.getLastUpdated().toISOString();
    var parsedData = [];
    try { parsedData = JSON.parse(content || "[]"); } catch(e) { parsedData = []; }
    return ContentService.createTextOutput(JSON.stringify({
      status: "ok",
      action: "download",
      updated_at: updated,
      data: parsedData
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

function doPost(e) {
  try {
    var folder = getOrCreateFolder();
    var file = getOrCreateFile(folder);
    var postData = (e && e.postData && e.postData.contents) || "";
    if (!postData) {
      return ContentService.createTextOutput(JSON.stringify({
        status: "error",
        message: "전송된 데이터가 없습니다."
      })).setMimeType(ContentService.MimeType.JSON);
    }
    var payload = JSON.parse(postData);
    var accountsData = payload.data !== undefined ? payload.data : payload;
    var dataStr = typeof accountsData === "string" ? accountsData : JSON.stringify(accountsData, null, 2);
    file.setContent(dataStr);
    return ContentService.createTextOutput(JSON.stringify({
      status: "ok",
      action: "upload",
      message: "Sync success",
      updated_at: new Date().toISOString(),
      count: Array.isArray(accountsData) ? accountsData.length : 1
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

🤖 서버 데몬 상태 및 제어

오라클 클라우드 우분투 인스턴스에서 백그라운드 서비스(systemd)로 24시간 자율 가동됩니다.

현재 실행 상태: IDLE (대기중)
데몬 실행 주기: 미국 장전 (22:30 KST) / 장후 (05:00 KST)
서버 OS 플랫폼: Oracle Linux / Ubuntu 22.04 LTS

🐧 오라클 우분투 서버 복사 및 구동 3단계

  • 1. 프로젝트 폴더 복사
    로컬에서 개발 완료 후 c:\oracle_web_server 폴더를 오라클 우분투 서버(SCP 또는 Git)로 복사합니다.
  • 2. 원클릭 셋업 스크립트 실행
    bash deploy_oracle_ubuntu.sh 실행 시 Python venv, 패키지 설치, 방화벽 개방 및 systemd 서비스 등록이 전자동 완료됩니다.
  • 3. 서비스 자동 시작 및 브라우저 접속
    sudo systemctl start jj_invest
    오라클 공인 IP (http://<오라클IP>:8000)로 어디서든 모바일/PC 접속 가능합니다.
