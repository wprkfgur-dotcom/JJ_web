  - 이미 마감되어 로컬에 저장된 과거 시세는 네트워크 통신 없이 0.001초 이내 즉시 반환.

- **장전 익일 모드 정밀 판별 엔진 구현 (`strategies/jongjong.py`)**:
  - `determine_next_mode()` 메서드 도입: 어제까지의 종가 시계열, 5일/20일 이동평균선(MA5, MA20), 전일 등락률(`i_col`), 전전일 등락률(`j_col`)을 바탕으로 엑셀 수식 및 백테스트 규칙과 100% 동일하게 익일(장전) 시장 모드를 판별.
  - 전일 폭락(-8% 이하 급락 등) 발생 시 익일 모드를 `Safe`로 즉각 전환하여 분할수 7, Safe 목표수익률 0.25%, 비선형 LOC 분할 주문표를 정확하게 산출.
- **실계좌 운용 상세 연동 개선 (`core/account_manager.py`)**:
  - `compute_account_details()`: 로컬 SQLite DB 및 계좌 일일 기록을 결합하여 장전 운용일의 시장 모드를 정밀 판정. Safe 모드 전환 시 하루 배분 예산(AR / 7) 및 주문표가 엑셀과 1원, 1주 단위까지 정확히 일치하도록 동기화.
- **금일 매수·매도 주문표 모드 배지 UI 추가 (`mobile/views/account_detail.py`)**:
  - 주문표 상단 헤더 우측에 거래 슬롯 상세 내역과 일관된 모드 배지(`Normal 모드`: 블루, `Safe 모드`: 옐로우/골드, `Riskoff 모드`: 레드)를 직관적으로 표시.
- **회귀 무결성 단위 테스트 추가 (`tools/run_app_tests.py`)**:
  - `test_tc15_determine_next_mode_safe_transition`: 10월 8일 폭락장 후 10월 9일 Safe 모드 전환 및 예산/주문표 산출 무결성 자동 검증 (15개 전체 TC 통과).

## [v2.3.0] - 2026-10-07

### 🚀 종종이 기본전략 핵심 업그레이드 (Core Strategy Upgrade)
- **위기준비금(AK) Risk-Off 전액 병합 메커니즘 도입 (`strategies/jongjong.py`)**:
  - **평상시 엄격 격리 보관**: 기존에는 운용 현금(Cash)과 위기준비금(AK 5%)이 섞여 있어 자금 소진 시 평상시에도 위기준비금이 매수에 침범되던 한계를 해결하고, 평상시(Normal/Safe)에는 AK를 안전 금고(Vault)에 엄격히 격리 보관.
  - **Risk-Off 진입 시 100% 전액 병합**: 시장 급락으로 Risk-Off 모드가 시작되는 당일, 그동안 모인 모든 위기준비금(AK)을 실가동 시드(AR)와 가용 현금(Cash)에 즉시 전액 병합(`ar_val += merged_ak`, `cash += merged_ak`, `ak_val = 0`)하여 위기 저점 분할매수 실탄으로 전진 배치.
  - **10거래일 복리 및 재적립**: 복리 정산일마다 실현손익의 5%를 운용 현금에서 차감하여 AK 금고로 이체·비축하는 선순환 구조 완성.
- **역사적 백테스트 검증 (2011년 3월 ~ 2026년 9월, 15.6년 SOXL 실데이터)**:
  - **최종 총자산**: 기존 $3,648만 달러(+36,385%) → **$4,624만 달러(+46,141%)**로 **+$975만 달러 (+26.7%) 초과 수익 달성**.
  - **리스크 관리**: 연복리(CAGR) 46.02% → **48.26%**, MDD는 -39.12% → **-39.80%**로 낙폭 증가는 불과 -0.68%p에 그치며 최적의 위험 대비 수익비(칼마 1.21, 샤프 1.15) 기록.
  - **연도별 승률**: 2011~2026년 총 16개 연도 중 15개 연도에서 기존 종종이 전략 초과 달성.
- **실계좌 및 UI 연동 최적화 (`core/account_manager.py`, `mobile/views/strategies.py`, `README.md`)**:
  - 실계좌 상세 조회 및 주문표 산출 시 최신 복리/병합된 AR 및 AK 상태를 완벽 연동.
  - 전략 가이드 페이지 내 위기준비금 Risk-Off 병합 시스템 안내 문구 보강.
